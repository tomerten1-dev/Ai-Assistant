- **P15:** "אני רוצה לקנות לחברים מתנה לחתונה" ← נדחה. וגם "אפשר שובר?" ← נדחה.
- **P23:** "אפשר בכלל לנסוע עם תינוק?" ← נדחה.

- **P20:** "למה שאזמין דווקא אצלכם?" ← נדחה. שאלת המכירה הכי חשובה שיש.

תיקנו את רשימת מילות התחום פעמיים היום, וזה עדיין קורה — כי בשיחה עם כרטיסים
