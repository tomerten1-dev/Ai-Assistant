# בקשת אישור: עדכון מלאי אוטומטי לבוט

*מסמך להעברה למי שאחראי על ה-IT בפינגווין. לא לשלוח לפני שהפיילוט רץ —
עד אז אין בו צורך.*

---

## מה מבקשים

להריץ סקריפט אחד, כל שלוש שעות, על המחשב שמארח את כונן F:.

הסקריפט קורא את קובץ ההתחייבויות, מחלץ ממנו **רק את מספרי החדרים הפנויים**,
ושולח אותם לשרת של הבוט. זה הכול.

## למה זה נדרש

הבוט מציג ללקוחות חבילות פנויות. הוא קורא את המלאי מקובץ שמתעדכן ידנית.
בלי עדכון אוטומטי, הבוט עלול להציע חדר שכבר נמכר — וזה פוגע בלקוח ובנציג
שצריך להתנצל.

## מה הסקריפט עושה

1. **מעתיק** את קובץ ההתחייבויות מ-F: לתיקייה זמנית (קריאה בלבד — הוא לא
   כותב, לא משנה ולא נועל את הקובץ המקורי).
2. **מפענח אותו מקומית** ומייצר רשימה של: מלון, תאריך, סוג חדר, וכמה פנויים.
3. **שולח רק את הרשימה הזאת** לשרת, ב-HTTPS, עם מפתח סודי.
4. מוחק את העותק הזמני. כותב שורה ליומן מקומי.

## מה הוא לא עושה

| | |
|---|---|
| **לא מעלה את קובץ האקסל** | הקובץ המקורי לא עוזב את הרשת של החברה |
| **לא שולח מידע על לקוחות** | שמות, טלפונים ומספרי הזמנה לא נכללים — יש בדיקה אוטומטית שמפילה את התהליך אם משהו כזה מופיע |
| **לא כותב לשום מקום ב-F:** | קריאה בלבד |
| **לא פותח שום פורט נכנס** | תעבורה יוצאת בלבד, HTTPS ליעד אחד |
| **לא מתחבר לשום מערכת אחרת** | לא למייל, לא ל-CRM, לא לאתר |
| **לא דורש הרשאות מנהל בזמן ריצה** | מספיקה הרשאת קריאה ל-F: וגישה לאינטרנט |

## מה צריך טכנית

- **Node.js LTS** מותקן על אותו מחשב (התקנה סטנדרטית, מ-nodejs.org)
- **הרשאת קריאה** לקובץ ההתחייבויות ב-F:
- **גישה יוצאת ב-HTTPS** לכתובת אחת: `bot.pingwin.co.il`
- **משימה ב-Task Scheduler**, כל 3 שעות, עם "Run whether user is logged on or not"

## מה קורה אם משהו נשבר

- הסקריפט נכשל → כותב ליומן, מסמן את המשימה ככושלת ב-Task Scheduler,
  והמלאי הקודם נשאר. שום דבר לא נמחק.
- הקובץ נשמר באמצע עריכה או נפגם → השרת **דוחה** אותו (יש בדיקה שמזהה
  ירידה חדה במלאי) וממשיך עם הנתונים הקודמים.
- המלאי מתיישן מעל 12 שעות → הבוט מפסיק לומר "נשאר חדר אחד", מוסיף ללקוח
  שורה שהזמינות משתנה, וממשיך להציג הצעות.

## לפני האישור

אפשר להריץ את הסקריפט **ידנית פעם אחת** ולראות בדיוק מה נשלח — הפלט הוא
קובץ טקסט קריא. אין שום דבר סמוי בתהליך, וכל הקוד פתוח לעיון.
