## 1. מה הפרויקט

בוט מכירות בעברית לאתר פינגווין (סקי): מבין את הלקוח, מסנן חבילות **פנויות באמת**
מתוך טבלת ההתחייבויות, מציג עד 3 הצעות, ומוביל ל"חזרו אליי" / "המשך להזמנה".
מוטמע ב-pingwin.co.il דרך Google Tag Manager בלבד. בהמשך — מוצר לחברות נוספות.

**כללים אדומים (לא משתנים בלי תומר):**
1. הבוט לא ממציא — כל תשובה עסקית מ-`config/*.json` או מהנתונים.
2. לא מציג הצעה שאינה פנויה.
3. **אפס מספרי כסף** בטקסט ללקוח (גם לא "€250" בדמי ביטול). המחיר המדויק — בהצעת המחיר / נציג.
4. לא מדרג מלונות זה מול זה.
5. לא זמני נסיעה — רק ק"מ.
6. המלצה על אתר — **רק מנומקת מנתונים מאושרים** (שאלה 25, טבלת `docs/resort-table.xlsx`).
7. בלי שמות מלונות ב-FAQ (חריג: לו"ז קייטנות).
8. שבת/כשרות/צרכים מיוחדים → נציג אנושי.

## 5. איך מריצים מקומית

```bash
git checkout fix/demo-polish && git pull
npm install            # פעם אחת (אין תלויות חיצוניות כבדות)
npm run dev            # מושך את הגרסה האחרונה מ-GitHub ומפעיל → http://localhost:8787
npm start              # הפעלה בלבד, בלי משיכה (PORT=xxxx לשינוי)
npm test               # כל הבדיקות; שורות "stub exhausted" הן רעש תקין
npm run test:ui        # בדיקות הווידג'ט בדפדפן אמיתי (Playwright)
node tests/test-bank.js
```
בלי `.env` השרת רץ במצב offline (בלי LLM) — מספיק לדמו ולבדיקות.
`.env.example` מפרט את המפתחות (OPENAI_*, LEAD_WEBHOOK_*, ALLOWED_ORIGINS).

## 6. איך אנחנו עובדים (השיטה, כדי שכל סשן ימשיך באותה צורה)

1. **תוכן = קונפיג, לא קוד.** תשובה עסקית חדשה נכנסת ל-`config/faq.json` / `guidance.json` / `departures.json` / `resort-profiles.json` / `data/hotel-facts.json` — עם ציטוט המקור (תומר, שאלון, דף באתר) בהערה.
2. **כל עובדה עם מקור.** מהאתר של פינגווין — ציטוט מילולי. מתומר — "תומר, תאריך, שאלה X". ממחקר אינטרנט — מסומן טיוטה עד אישור.
3. **כל שינוי = בדיקה.** מוסיפים מקרה ב-`tests/` (לרוב `test-end-to-end.js` או קובץ ייעודי) שמצמיד את ההתנהגות; `npm test` חייב להיות ירוק לפני commit.
4. **מודדים עם הבנק.** `node tests/test-bank.js` אחרי כל שלב; הציון מותר לו רק לעלות (82 → 85).
5. **Commit אחד לכל נושא, הודעה מלאה באנגלית** שמסבירה מה ולמה — זה יומן השינויים המפורט (`git log`). `docs/STATUS.md` מסכם, ומתעדכן באותו commit.
6. **הכללים האדומים בודקים אוטומטית**: בנק (מספרים מומצאים), `test-faq.js` (כסף ב-FAQ), `test-recommend.js` (כסף/מלונות/זמנים בהמלצות).
