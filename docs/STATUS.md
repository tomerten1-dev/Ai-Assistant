## 1. מה הפרויקט

בוט מכירות בעברית לאתר פינגווין (סקי): מבין את הלקוח, מסנן חבילות **פנויות באמת**
מתוך טבלת ההתחייבויות, מציג עד 3 הצעות, ומוביל ל"חזרו אליי" / "המשך להזמנה".
מוטמע ב-pingwin.co.il דרך Google Tag Manager בלבד. בהמשך — מוצר לחברות נוספות.

**כללים אדומים (לא משתנים בלי תומר):**
1. הבוט לא ממציא — כל תשובה עסקית מ-`config/*.json` או מהנתונים.
2. לא מציג הצעה שאינה פנויה.
3. **אפס מספרי כסף** בטקסט ללקוח (גם לא "€250" בדמי ביטול). המחיר המדויק — בהצעת המחיר / נציג.
4. לא מדרג מלונות זה מול זה.
5. לא זמני נסיעה — רק ק"מ.
6. המלצה על אתר — **רק מנומקת מנתונים מאושרים** (שאלה 25, טבלת `docs/resort-table.xlsx`).
7. בלי שמות מלונות ב-FAQ (חריג: לו"ז קייטנות).
8. שבת/כשרות/צרכים מיוחדים → נציג אנושי.

## 5. איך מריצים מקומית

```bash
git checkout fix/demo-polish && git pull
npm install            # פעם אחת (אין תלויות חיצוניות כבדות)
npm start              # → http://localhost:8787   (PORT=xxxx לשינוי)
npm test               # כל הבדיקות; שורות "stub exhausted" הן רעש תקין
node tests/test-bank.js
```
בלי `.env` השרת רץ במצב offline (בלי LLM) — מספיק לדמו ולבדיקות.
`.env.example` מפרט את המפתחות (OPENAI_*, LEAD_WEBHOOK_*, ALLOWED_ORIGINS).
