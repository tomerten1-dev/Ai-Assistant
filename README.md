# 🐧 בוט התאמת חופשות סקי — פינגווין (דמו)

צ'אט צף בעברית לאתר פינגווין: הלקוח כותב בשפה חופשית, הבוט משלים מה שחסר
בשאלה-שתיים לכל היותר, ומציג **3 חבילות אמיתיות שפנויות בפועל** מתוך קובץ
ההתחייבויות של חורף 2026/27.

## הרצה מקומית

```bash
node server/server.js
```

ולגלוש אל: **http://localhost:8787**

זהו. בלי התקנות, בלי תלויות — Node בלבד.

### שני מצבי עבודה

| מצב | מה צריך | איך זה מבין עברית |
|---|---|---|
| **דמו (ברירת מחדל)** | כלום. עובד עכשיו, בחינם | מנתח דטרמיניסטי (זיהוי מספרים, גילאים, חודשים, יעדים) |
| **Claude** | מפתח API בקובץ `.env` | מודל `claude-sonnet-4-6` דרך פרוקסי בשרת |

לשדרוג ל-Claude: העתיקו את `.env.example` ל-`.env`, הדביקו מפתח מ-console.anthropic.com,
והפעילו מחדש את השרת. **המפתח לעולם לא מגיע לדפדפן** — כל הקריאות דרך השרת.

### עדכון נתונים (כשמגיע קובץ התחייבויות/ליווי חדש)

שימו את הקבצים ב-`source-data/` ואז:

```bash
npm run build:data
```

## הטמעה באתר האמיתי

שורה אחת לפני סגירת ה-`</body>`:

```html
<script src="https://<host>/pingwin-bot.js" data-pingwin-bot></script>
```

הווידג'ט עצמאי לגמרי (Shadow DOM) — לא מתנגש עם ה-CSS או ה-JS של האתר.
צבעים ופונט: אובייקט `THEME` בראש `public/pingwin-bot.js` (פלייסהולדרים לצבעי פינגווין).

## ארכיטקטורה — מי מחליט מה

```
לקוח כותב חופשי ──► הבנת שפה (Claude / רג'קס) ──► slots
                                                    │
                    קוד דטרמיניסטי בלבד ◄───────────┘
                    (data/filter.js — סינון זמינות,
                     תפוסה, קייטנות, פיצול חדרים)
                                                    │
                    ניסוח בעברית ◄──────────────────┘
                    (עד 8 מועמדים; ה-AI לא בוחר ולא ממציא)
```

**היקום הסגור:** רק מה שבקובץ ההתחייבויות קיים עבור הבוט. אתר פינגווין משמש
להעשרת תוכן בלבד (יישוב, siteID, הרכבי חדרים) — לא כמקור הצעות.

## פרטיות — שני שערי PII

קובצי המקור מכילים שמות לקוחות, מספרי הזמנה ופרטי ילדים. לכן:

1. **פרסור בצד שרת בלבד** — האקסל לא מגיע לדפדפן. הניקוי קורה בתוך הפרסר.
2. **שער בילד** — `npm run build:data` נכשל אם ה-JSON הציבורי מכיל תו עברי
   בשדה חדר או רצף של 6 ספרות.
3. `source-data/` ו-`server-data/` (לידים) חסומים ב-`.gitignore`.

## טסטים (סעיף 9 בפרומפט)

```bash
node tests/run-tests.js          # פרסור + מנוע סינון (27 טסטים)
node tests/test-offline.js       # מצב דמו מקצה-לקצה (12)
node tests/test-orchestration.js # צנרת Claude עם מודל מדומה (12)
```

| דרישה | איפה מכוסה |
|---|---|
| 1. משפחה 2+2 (5 ו-9) + קייטנה → שתי קבוצות הגיל באותו שבוע, חלקי מסומן | run-tests [1] |
| 2. הודעה אחת מלאה → אפס שאלות, 3 הצעות | test-offline [2], test-orchestration [2] |

| 4ב. פברואר בצרפת → הסבר + חלופות | run-tests [4b], test-offline [2] |
| 4ג. ואקאנס + "שמור" → אפס הופעות | run-tests [4c] |
| 5. טסט PII על ה-JSON הציבורי | run-tests [5] + שער הבילד |

| 7. prompt injection → נדחה | כללים אדומים ב-system prompt (מצב Claude); במצב דמו אין מודל שאפשר להזריק לו. בדיקה ידנית אחרי חיבור מפתח |
